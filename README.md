# Clock

Учебный проект решения (Solution) на C#, объединяющий два графических фреймворка платформы .NET: классический **Windows Forms** и современный **WPF (Windows Presentation Foundation)**. Программа представляет собой кастомизируемые десктопные часы с возможностью динамической смены шрифтов, цветов, интеграцией с системным треем и реестром Windows.

---

## Связь кода с теорией

* **Многомодульная структура BCL:** Решение демонстрирует параллельное использование библиотек WindowsForms и WPF для отрисовки графических интерфейсов.
* **Автосвойства и Инкапсуляция:** В файле `FontDialog.cs` реализованы автосвойства для передачи параметров выбранного шрифта: `public new Font Font { get; set; }`.
* **Динамические структуры данных:** Поиск и индексация шрифтов по дисковым путям реализованы через хэш-таблицу `Dictionary<string, string>`, обеспечивающую быстрый доступ к файлам по их короткому имени.
* **Рекурсивный обход директорий:** Поиск файлов кастомных цифровых шрифтов во вложенных папках реализован через классический алгоритм рекурсивного метода `Traverse`, который на каждом шаге считывает файлы `*.ttf`/`*.otf` через `Directory.GetFiles` и повторно вызывает сам себя для всех обнаруженных поддиректорий `Directory.GetDirectories`.
* **Потоковый ввод-вывод (Сериализация):** Сохранение текущего состояния и конфигурации приложения при закрытии формы и его последующее восстановление реализовано через текстовые потоки `StreamWriter` и `StreamReader` в локальный инициализационный файл `Settings.ini`.

## Разбор проектов и структуры решения

### 1. Модуль Clock (Windows Forms приложение)
Основной рабочий проект, реализующий кастомизируемый виджет цифровых часов.

* **`Form1.cs` (MainForm):** 
  * При запуске автоматически выравнивает свое положение в правом верхнем углу рабочего стола с помощью `Screen.PrimaryScreen.Bounds.Width`.
  * Работает на базе компонента `System.Windows.Forms.Timer` с событием `timer_Tick`, которое каждую секунду считывает системное время через `DateTime.Now.ToString("HH:mm:ss")` и обновляет текст. Также поддерживает вывод даты и дня недели по чекбоксам.
  * Реализует режим "безрамочного виджета": по кликам или через контекстное меню `ContextMenuStrip` можно скрыть элементы управления, убрать рамку окна (`FormBorderStyle.None`) и включить прозрачность фона через `TransparencyKey`.
  * Интегрировано системное Windows API через **P/Invoke** и атрибут `[DllImport("kernel32.dll")]` для вызова `AllocConsole()`, что позволяет параллельно выводить отладочные логи в консоль операционной системы.
  * Поддерживает сворачивание в трей через элемент `NotifyIcon` с контекстным меню.
* **`FontDialog.cs` (Окно выбора шрифта):**
  * Кастомная форма, которая динамически сканирует папку `Fonts` на наличие файлов цифровых шрифтов.
  * Загружает файлы во внутреннюю коллекцию `PrivateFontCollection` через `AddFontFile()`, позволяя пользователю выбрать шрифт из выпадающего списка `ComboBox` и настроить его размер через `NumericUpDown`.
* **Управление реестром (Автозагрузка):** 
  * Метод `SetAutostart` работает с системным реестром Windows через класс `RegistryKey`. 
  * При включении тумблера программа открывает ветку `SOFTWARE\Microsoft\Windows\CurrentVersion\Run` и прописывает туда имя приложения и путь к исполняемому файлу `Application.ExecutablePath`, обеспечивая старт часов вместе с запуском операционной системы.
* **Конфигурация `Settings.ini`:**
  * Файл инициализации, в который построчно записываются параметры: координаты окна (X и Y), состояния чекбоксов (`TopMost`, `ShowControls`, `ShowDate`, `ShowWeekday`, `Autostart`), путь к файлу текущего шрифта, его размер, а также ARGB-коды цветов текста и фона. При ошибке чтения файла (например, при первом запуске) срабатывает блок `catch`, который перехватывает `Exception` и сбрасывает настройки на дефолтные.

### 2. Модуль WPF (Приложение на Windows Presentation Foundation)
* **`MainWindow.xaml.cs` / `App.xaml.cs`:** Параллельный модуль в решении, представляющий собой заготовку окна под разметку XAML для демонстрации аналогичного функционала часов, но с использованием графической подсистемы WPF и её структуры инициализации приложения `Application`.

## Инструкция по сборке

1. Откройте файл решения `Clock.sln` в IDE Visual Studio.
2. Убедитесь, что в корневой директории сборки (рядом с исполняемым файлом или в путях проекта) находится папка `Fonts` с необходимыми цифровыми шрифтами `*.ttf` (например, `DIGITALDREAM.ttf`) для их корректного рекурсивного подтягивания в форму настроек.
3. Установите проект `Clock` как запускаемый (*Set as Startup Project*) и соберите его в конфигурации `Debug` или `Release`. Виртуальная машина **CLR** запустит скомпилированный **ILcode**.
